# 明理 · 裁判文书论证结构标注系统

小组合作网页作业。围绕裁判文书中的事实、规范与裁判结论，完成命题标注、关系建立、人工复核与成果导出。

**当前阶段：仅实现前端。** 项目使用 Vue 3、HTML、CSS、JavaScript，没有后端服务或数据库。示例文书与分歧均为虚构；模拟登录、角色与任务分配不提供真实认证、权限隔离或多人协作。

## 快速启动（Windows 推荐）

1. 首次使用先安装 [Node.js 24 LTS](https://nodejs.org/)；已经安装受支持版本的同学可以跳过。
2. 下载并解压完整项目，双击根目录中的 **`启动网页.cmd`**。
3. 脚本会检查环境、自动安装依赖，然后打开浏览器。进入登录页后，点击 **“一键体验演示空间”** 即可查看网页。

首次启动或依赖更新后需要联网安装，后续通常可以直接打开。使用期间请保留启动窗口；关闭窗口或按 `Ctrl+C` 即可停止服务。浏览器未自动打开时，复制窗口中显示的本地地址访问。默认端口为 `5173`，被占用时会自动选择其他空闲端口；避免重复启动即可保持地址稳定，本地演示数据按地址分别保存。

**为什么不直接双击 HTML？** 本项目是 Vue 模块化工程，根目录的 `index.html` 是开发入口，需要构建工具处理 `.vue` 文件。双击 `启动网页.cmd` 就是本项目对应的一键启动方式，无需手动执行终端命令，也不需要启动后端或数据库。

macOS / Linux 用户安装 Node.js 后，可在项目目录执行 `npm start`，同样会自动准备依赖并打开网页。

## 手动运行（开发时使用）

需要 Node.js 20.19+ 或 22.12+，推荐 Node.js 24 LTS。

```bash
npm install
npm run dev
```

打开终端输出的本地地址，通常为 `http://127.0.0.1:5173`。首次进入登录页面，可点击“一键体验演示空间”，或输入任意姓名与至少 6 位密码。**请勿输入真实密码**，演示登录不保存密码。

```bash
npm run build    # 生产构建，输出 dist/
npm run preview  # 本地预览生产构建
npm test         # 原文定位、关系与 SVG 转义等核心逻辑测试
npm run format  # 统一源代码格式
```

路由采用 Hash 模式，静态服务器无需配置 history 回退。通过 Vite 或静态 HTTP 服务器访问，不要直接双击源代码中的 HTML 文件。

## 前端架构

```text
启动网页.cmd                # Windows 双击启动入口
scripts/start.mjs            # 检查环境、安装依赖、启动并打开网页
public/
  favicon.svg                # 站点图标
src/
  main.js                    # Vue 应用入口
  App.vue                    # 顶部导航、账户菜单、全局提示
  styles.css                 # 统一视觉规范与响应式布局
  router/index.js            # 页面路由、演示登录拦截
  views/
    LoginView.vue            # 登录及一键体验
    TasksView.vue            # 任务管理
    DocumentsView.vue        # 文书管理
    WorkbenchView.vue        # 原文选区、标注编辑、关系、提交
    ReviewView.vue           # 人工复核
    ExportView.vue           # 数据与图示导出
    GuideView.vue            # 标签指南、帮助
  components/                # 图标、弹窗、状态、空状态、论证图
  stores/workspace.js        # 共享响应式状态、保存事务、任务状态汇总
  services/api.js            # 模拟数据接口，后端接入的主要替换点
  data/seed.js               # 虚构演示数据、标签与关系定义
  utils/annotation.js        # 偏移校验、选区重叠检查、ID、下载
  utils/graph.js             # 论证图布局及安全 SVG 导出
tests/annotation.test.js     # 核心数据逻辑测试
```

数据流：`页面组件 → workspace store → api 适配层 → 浏览器存储`。页面不直接访问数据库；后端接入时将 `api.js` 替换为 HTTP 实现，并把当前整体保存拆分为按资源的增删改查。错误应统一抛出，由状态层或页面反馈给用户。

Vue 组件统一使用 `<script setup>` 与 Composition API，JavaScript 使用单引号和分号。公共 UI 放在 `components`，纯逻辑放在 `utils`。使用 Prettier 统一格式，没有引入 UI 组件库；图标来自 Lucide，字体使用系统回退，不依赖外部字体服务。

### 本地状态与标注模型

- `localStorage['mingli-demo-v1']`：任务、文书、标注、关系、裁定和导出记录；同浏览器共享，刷新后保留。
- `sessionStorage['mingli-session-v1']`：当前标签页的演示姓名与角色，不保存密码。切换用户不会产生独立的数据空间。
- 工作台使用独立草稿及最多 50 步撤销记录；点击“保存草稿”或 `Ctrl/Cmd + S` 保存。路由跳转、退出登录和关闭页面时检查未保存内容。
- `annotations[]`：`{ id, start, end, text, label, subtype, note }`。
- `relations[]`：`{ id, sources: string[], target, type }`。组合关系 `J` 支持多个起点；其他类型使用一个起点。
- 偏移基于规范化原文的 **UTF-16 code unit**：`start` 包含、`end` 不包含，应满足 `text.slice(start, end) === annotation.text`。导入时统一为 LF 换行并去除全文首尾空白，保存后原文固定。
- 第一版禁止重叠标注；删除命题时连带删除引用关系；检查原文偏移、标签、GM 子类型与关系端点后才能提交。
- 文书状态：`未开始 → 标注中 → 待裁定 → 已完成`。提交后只读，裁定页可以修改分歧标签。前端不生成真实的多人分歧。
- 任务状态由文书状态汇总；演示进度按未开始 0%、有草稿 50%、已提交或完成 100%计算，任务详情中有明确说明。
- 每份文书当前只属于一个任务。删除任务保留文书；已关联任务的文书不可直接删除。

标签：`SF` 个别事实判断、`GF` 一般事实判断、`SM` 个别规范判断、`GM` 一般规范判断。关系：`S` 支持、`A` 反对、`J` 组合、`M` 匹配、`I` 同一。指南版本固定为 `v1.0`。

## 演示与验证流程

1. 一键登录，查看首页统计与任务筛选。
2. 在文书管理手动录入一份文书，或上传 1 MB 以内、正文不超过 100,000 字的 UTF-8 TXT。
3. 新建任务，选择刚导入的文书及成员。
4. 进入工作台，选取原文片段添加标签；标注两个以上命题后添加关系，检查关系图。
5. 修改后使用撤销/重做，保存并刷新验证持久化；未保存直接跳转可验证离开提醒。
6. 通过检查并提交，在裁定页核对结果后完成复核。
7. 选择文书导出 JSON 或单份 SVG。JSON 保留全文、原文偏移、标签、关系与指南，SVG 节点展示摘要并通过 `title` 保留完整命题。
8. 使用预置“物业服务”任务体验两位成员之间的标签分歧裁定。
