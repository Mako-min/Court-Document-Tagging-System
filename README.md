# 裁判文书论证结构标注系统

Court Document Tagging System 面向法学研究与教学，围绕裁判文书中的**裁判理由**，帮助使用者识别命题、标记命题性质、建立论证关系，并以图示呈现裁判结论的推理过程。系统通过多人独立标注与人工裁定，形成可复用的结构化标注数据。

项目目前处于需求梳理阶段，尚未开始代码实现。以下内容介绍项目目标与规划功能。

## 为什么要做

分析一份裁判文书，需要理解法院认定了哪些事实、引用了哪些规范，以及这些理由如何支持或反对某个判断。这些信息分布在连续的自然语言文本中。面对大量文书，研究团队需要一套统一的方法，将原文中的命题及其关系整理成便于查看、比较和复用的论证结构。

本项目希望为以下工作提供支持：

- **法律论证研究**：区分事实判断与规范判断，梳理理由与结论之间的联系，为分析和比较裁判文书中的论证模式提供材料。
- **团队协作标注**：让多人按照同一套标注指南独立工作，再由裁定者处理分歧，形成统一的最终结果。
- **法学教学与练习**：用论证图示展示推理过程，让学生通过标注练习及与标准样例的对照，学习法律论证分析。
- **研究数据积累**：保留命题对应的原文位置、标签和关系，形成可复用的数据集，为后续自动化论证挖掘、模型训练与评估提供基础。

## 能做什么

### 1. 导入文书并组织标注任务

计划支持 PDF、Word 和纯文本的单文件导入、批量上传，以及手动录入或粘贴文本。文档可设置名称和案例类型，便于整理与分配。

系统将辅助提取文书中的裁判理由，并允许人工校正提取范围。任务创建者可以配置标签体系和标注指南、分配标注人员、指定裁定者；同一份文书可以分配给多名标注者独立处理。

### 2. 从原文中提取并标注命题

标注者通过选择原文片段建立命题，为其编号并赋予标签，也可以先划分命题、再补充标签。命题列表展示完整文本，并记录对应的原文字符位置，便于回到上下文核对。标注过程中可修改标签或删除命题。

规划中的一级标签包括：

| 标签 | 命题性质 | 标注内容 |
| --- | --- | --- |
| SF | 个别事实判断 | 关于具体案件中对象、行为或事件的事实判断 |
| GF | 一般事实判断 | 常识、经验法则、行业知识、科学规律等一般性判断 |
| SM | 个别规范判断 | 法院针对本案作出的规范性评价或裁判结论 |
| GM | 一般规范判断 | 法律条文、合同条款、交易习惯等规范性依据 |

一般规范判断进一步区分为法律条文、法律解释、合同及合同解释、习惯与行业惯例、道德与价值观念、其他规范判断。标签体系在任务开始后保持固定，并记录对应的指南版本，以便理解和复用标注结果。

### 3. 建立论证关系并生成图示

在命题标注的基础上，通过图形交互连接命题，表达它们在论证中的作用。规划支持以下五类关系：

| 关系 | 含义 |
| --- | --- |
| 支持（S） | 一个命题为另一个命题的成立提供理由 |
| 反对（A） | 一个命题为另一个命题的不成立提供理由 |
| 组合（J） | 多个命题共同构成缺一不可的理由组合 |
| 匹配（M） | 个别判断与一般判断之间的对应，如案件事实与规范要件的匹配 |
| 同一（I） | 多个命题在语义上表达同一判断内容 |

系统将根据命题及关系生成论证图示，并支持多个命题共同支持一个结论、嵌套关系，以及同一文书中的多个独立论证结构。图示可自动布局、手动调整和缩放浏览，并与标注内容联动，方便查看和核对推理结构。

### 4. 汇集多人结果并进行人工裁定

同一文书的各份独立标注结果将集中展示，由裁定者结合原文人工比对命题划分、标签选择和论证关系。裁定者可以采用已有结果，也可以重新标注，形成最终版本。

裁定完成后，标注者可以对照自己的结果与最终结果，了解不同理解及其处理结果。

### 5. 导出和复用标注成果

规划提供两类输出：

- **论证图示**：导出为 PNG、JPG 或 SVG，用于研究展示与教学材料。
- **结构化数据**：导出为 Excel 或 JSON，包含命题、标签、关系及原文定位等信息，供后续整理、分析或模型训练使用。

导出结果附带对应版本的标注指南，并支持自定义命名、打包下载及下载用户记录。规划同时支持将导出的结果重新导入，便于后续复用。

### 6. 支持教学标注练习

教学场景下，教师可以制作标准标注样例，学生通过独立入口完成标注，再将自己的结果与标准结果进行对照。该功能旨在帮助学生练习命题划分、标签判断和论证关系分析。

## 主要流程与角色

**创建任务 → 独立标注 → 冲突裁定 → 结果输出**

任务创建者准备文书和标注规则，标注者完成各自的标注，裁定者形成最终结果，随后输出图示和结构化数据。

| 角色 | 主要职责 |
| --- | --- |
| 任务创建者 | 导入文书、配置标签与指南、分配任务、指定裁定者 |
| 标注者 | 处理分配的文书，完成命题和关系标注，查看裁定后的结果 |
| 裁定者 | 查看各份标注结果，人工比对、选择或修改内容，确定最终版本 |

同一用户可以承担多种角色，具体操作由所获权限决定。
